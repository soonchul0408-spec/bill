# 지역산업 비교 인사이트 설계

## 목적

이 서비스는 지역별 공개자료를 나열하는 도구에서 나아가, **같은 산업·같은 사업 단계·같은 기간**을 기준으로 지역산업을 비교하고 판단 근거를 보여주는 서비스가 되는 것을 목표로 한다.

점수는 투자 추천이나 사업 성공 예측이 아니다. 각 점수에는 계산식, 비교군, 원문 근거, 자료 기준일을 함께 표시한다.

## 현재 구현 상태

| 영역 | 상태 | 현재 범위 |
| --- | --- | --- |
| 정책 추진력 | 일부 구현 | 사업·법안 공개 건수와 단계 기반의 기본 비교 |
| 재정 실행력 | 일부 구현 | 지방재정365 예산현액·지출액을 받아 집행률을 표시할 수 있는 구조 |
| 산업 기반 | 일부 구현 | 관련 기업 연결 근거와 DART 기업·공시 자료 |
| 시장 반응 | 사례 수준 구현 | 정책 이벤트와 종목의 사례형 5·20거래일 반응, 최신 종가 API |
| 신뢰도 | 일부 구현 | 실시간/샘플 구분, 출처와 확인일 표시 |
| 법안 실제 데이터 | 대기 | 국회 의안정보 API URL·서비스키가 필요 |

현재 전국 지도 `비교 기준` 화면은 정책 모멘텀, 실행 공개도, 기업 근거, 데이터 신뢰도의 초기 비교 화면이다. 아래의 보정·비교군·시장 반응 계산까지는 아직 구현하지 않았다.

## 비교 단위와 동일 조건 규칙

비교 단위는 다음 네 가지를 항상 함께 저장한다.

```text
지역 + 산업 + 기준 기간 + 사업/정책 단계
```

- 지역: 시·도, 필요하면 시·군·구까지 확장
- 산업: 반도체, 방산, 이차전지, AI·데이터센터, 전력·에너지 등 공통 분류
- 기준 기간: 월·분기·연 단위 중 하나를 명시
- 사업 단계: 발의, 입법예고, 심사, 통과, 예산안, 공고, 사업자 선정, 착공, 집행 등

서로 산업이 다른 지역을 단순 건수로 순위화하지 않는다. 기본 비교군은 `동일 산업 + 동일 단계군 + 동일 기간`이며, 비교군이 부족하면 화면에 `비교군 부족`으로 표시한다.

## 다섯 축과 초기 가중치

초기 총점은 100점이며, 아래 가중치는 화면 검증 후 조정할 수 있다.

| 축 | 가중치 | 핵심 지표 | 비교 방식 |
| --- | ---: | --- | --- |
| 정책 추진력 | 25 | 법안 단계, 지정·승인·협약 수, 최근 업데이트일 | 같은 산업·기간의 단계 가중치 및 정책 밀도 |
| 재정 실행력 | 25 | 예산현액, 지출액, 집행률, 전년 대비 변화 | 같은 산업·기간의 집행률과 증감률 |
| 산업 기반 | 20 | 관련 기업 수, 직접 근거 기업 비율, 상장사 시가총액 | 지역 규모 보정 및 동일 산업 비교 |
| 시장 반응 | 15 | 이벤트 후 5·20거래일 수익률, KOSPI 대비 초과수익률 | 동일 이벤트 창과 벤치마크 비교 |
| 신뢰도 | 15 | 공식 원문 여부, 데이터 최신성, 직접 참여 근거 여부 | 출처 품질과 확인일 기반 |

### 1. 정책 추진력

`정책 추진력 = 단계 가중치 × 정책 건수 + 최근성 보정`

- 단계 가중치는 단순 발의보다 통과·예산 확정·사업자 선정에 높게 둔다.
- 최근성은 기준일에서 자료 업데이트일까지의 일수로 감점한다.
- 건수는 지역의 전체 사업 수가 아니라 같은 산업·같은 기간의 `정책 밀도`로 정규화한다.

### 2. 재정 실행력

`집행률 = 지출액 / 예산현액 × 100`

`재정 실행력 = 집행률 점수 + 전년 대비 집행률 변화 점수`

- 예산현액이 0이거나 없으면 0점이 아니라 `산출 불가`로 표시한다.
- 서로 다른 규모의 지역을 비교하기 위해 총액보다 집행률을 우선한다.
- 향후 인구·사업장 수·지역 GRDP 등의 분모를 확보하면 1인당/사업장당 예산도 보조 지표로 제공한다.

### 3. 산업 기반

`산업 기반 = 직접 근거 기업 비율 + 관련 기업 수 보정 + 상장사 시가총액 보조 지표`

- 기업이 단순히 같은 업종이라는 사실만으로 직접 참여 기업으로 표시하지 않는다.
- 공시, 협약, 공급계약, 사업 공고 등 직접 연결 원문이 있는 기업만 직접 근거로 계산한다.
- 상장사 시가총액은 산업 기반의 보조 지표이며, 기업 수나 지역 경제력의 대체값으로 쓰지 않는다.

### 4. 시장 반응

`초과수익률 = 종목 수익률 - KOSPI(또는 적절한 업종 지수) 수익률`

- 모든 이벤트는 발표일 기준 +5, +20 거래일을 동일하게 계산한다.
- 정책 이벤트, 실적 발표, 대형 수주·계약, 업황 뉴스가 겹치면 교란 요인으로 함께 기록한다.
- 정책 효과로 단정하지 않으며 `정책 연관 사례의 시장 관찰`로 표기한다.
- 실제 과거 가격·지수 API가 연결되기 전까지 기존 사례의 수치는 `사례 데이터` 배지를 유지한다.

### 5. 신뢰도

신뢰도는 점수의 근거 품질을 나타내며, 자료량을 의미하지 않는다.

- 공식 원문 URL 존재 여부
- API에서 실제 수신한 자료인지 여부
- 기준일 및 최종 확인일
- 기업의 직접 참여 근거 여부
- 비교군 표본 수

## 화면 설계

### 전국 지도 > 비교 기준

각 지역 행에 다음을 표시한다.

```text
총점 / 100
정책 · 재정 · 산업 기반 · 시장 반응 · 신뢰도
비교군: 반도체 · 사업자 선정 이후 · 2026년
근거 n건 · 실제 API n건 · 기준일 YYYY-MM-DD
```

점수를 누르면 지역 상세 화면으로 이동하며, 각 축의 원문 자료와 산식 세부 내역을 확인한다.

### 지역 상세

- 내 지역 점수와 비교군 중앙값
- 전국 평균, 동일 산업 평균, 동일 단계 평균을 구분해 표시
- 데이터 부족/산출 불가 사유
- 원문 출처, API 제공기관, 확인일

### 케이스 스터디

- 시장 반응은 지역 순위가 아니라 사례 분석 탭에서 제공
- 이벤트, 종목, 벤치마크, 교란 요인, 5·20일 초과수익률을 한 묶음으로 표시
- 실제 가격 데이터와 사례형 계산 데이터를 배지로 구분

## 필요한 데이터 모델

각 지역·산업 집계는 아래 공통 필드를 가진다.

```js
{
  regionId,
  industry,
  period: { start, end, basis },
  stageGroup,
  policy: { count, weightedCount, latestUpdatedAt },
  finance: { budgetAmount, expenditureAmount, executionRate, yearOverYearRate },
  industryBase: { companyCount, directEvidenceCount, directEvidenceRate, listedMarketCap },
  market: { sampleCount, excessReturn5, excessReturn20, benchmark },
  confidence: { officialSourceRate, liveRecordRate, directEvidenceRate, latestVerifiedAt },
  score: { policy, finance, industryBase, market, confidence, total },
  comparisonGroup: { key, sampleSize, median, percentile },
  evidence: []
}
```

## API와 데이터 준비 순서

1. 현재 연결 유지: 지방재정365 세부사업별 세출현황, OpenDART, 금융위원회 주식시세 API
2. 국회 실제 법안: 공공데이터포털 의안정보 통합 API의 URL·서비스키를 `ASSEMBLY_BILL_API_URL`, `ASSEMBLY_BILL_API_KEY`에 설정
3. 과거 주가·벤치마크: 종목별 일별 과거 가격과 KOSPI/업종지수 시계열을 동일 공급원 또는 라이선스 허용 공급원으로 확보
4. 산업 보정 분모: 지역별 고용·사업체·GRDP, 특허·수출 등 공식 통계를 추가
5. 집계 파이프라인: 원천 데이터를 월/분기 기준으로 저장하고 비교군별 평균·중앙값·백분위를 계산

유료 데이터가 필요한 경우, 무료 데이터와 섞어 쓰지 말고 화면에 데이터 제공 범위와 라이선스를 명시한다.

## 구현 로드맵

1. **비교 스키마 구현**: 위 공통 모델과 기준일·비교군·산출 불가 상태를 프론트/서버에 추가
2. **정규화 계산 구현**: 동일 산업·단계·기간 필터, 전국/비교군 평균·중앙값·백분위 계산
3. **근거 화면 구현**: 점수별 산식, 원문 URL, 최신일, 표본 수를 상세 화면에 표시
4. **시장 반응 파이프라인 구현**: 실제 과거 가격·지수 데이터로 이벤트 창과 초과수익률을 계산
5. **국회 API 연결**: 키 발급 뒤 실제 법안으로 전환하고 샘플과 실제 자료를 명확히 구분

## 다른 맥에서 작업하기

```sh
git clone https://github.com/soonchul0408-spec/bill.git
cd bill
npm install
```

`.env.example`을 참고해 각자의 `.env.local`을 만들고 본인 API 키를 입력한다. `.env.local`은 비밀값이므로 GitHub에 커밋하지 않는다.

```sh
# 터미널 1: API 프록시
npm run api

# 터미널 2: Vue 개발 서버
npm run dev
```
